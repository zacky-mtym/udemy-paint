# お絵かき

ブラウザだけで動く、シンプルなお絵かきアプリです。インストールやビルドは不要です。

## 使い方

`index.html` をブラウザで開いてください。

キャンバス上でドラッグすると線が引けます。マウスとタッチの両方に対応しています。

| 操作 | 内容 |
| --- | --- |
| ペン | 選んだ色で描く。カーソルはペンの形になる |
| 消しゴム | 白で消す。カーソルは消しゴムの形になる |
| 色 | プリセット、またはカラーピッカーで選ぶ |
| 太さ | 1〜48 の範囲で線の太さを変える |
| 取り消す | 直前の操作を戻す。`Ctrl+Z`（Mac は `Cmd+Z`）でも可 |
| 全部消す | キャンバスを白紙に戻す |
| 保存 | 描いた絵を PNG でダウンロードする |

## ファイル

- `index.html` — 画面
- `style.css` — 見た目
- `app.js` — 描画
- `cursors/` — ペンと消しゴムのカーソル画像
